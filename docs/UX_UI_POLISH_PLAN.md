# Entropy UX/UI Polish Plan

## Purpose

Polish the existing Entropy interface without inventing new product surfaces, changing analytics behavior, or weakening the authority of detailed evidence views.

Every UX/UI change follows this chain:

**Evidence → Problem → Correction → Verification**

If a visible problem cannot be demonstrated, it is not changed.

## Scope rules

- Chromium/current Chrome is the supported visual target for this pass.
- Firefox-specific work is out of scope.
- Intelligence remains additive.
- Existing metrics, tables, routes, and evidence views remain authoritative.
- Replay semantics are not changed during global foundation work.
- No parallel card, panel, token, or design system is introduced.
- Prefer existing shared primitives and theme tokens.
- Missing data, identity, and evidence semantics are never altered by presentation work.
