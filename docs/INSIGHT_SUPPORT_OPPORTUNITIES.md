# Support Opportunities

First release: selected-provider reviews for Stand Your Ground in WvW, based on a reference 24-second cooldown. The existing rotation, replay, and mechanics records are read without changing metric calculations or parsing.

Each record joins a prior observed cast to a squad teammate's five-second pre-down window by fight ID. It includes recorded casts within that window, estimated reference recharge progress, provider survival constraints, effect states, mechanics events, source, assumptions, and replay navigation. Missing data is unknown. Every review retains actual availability and rescue outcome as unresolved.

The model integrates alacrity/chill/resistance transitions. Missing states or unsupported overlaps widen the reference range. This is not a historical patch match and does not model trait reductions, resets, ammunition, resources or loadout changes. A prior cast does not prove current equipment. Position-to-skill-range calibration is not established by this module.

Next steps:
1. Preserve and match game build/mode; verify historical skill IDs, cooldowns, effect timing, and modifier interactions.
2. Validate completed casts, coverage gaps, resource/ammunition mechanics and reset events before expanding skills.
3. Calibrate replay distance in world units; include line of sight, target caps, subgroup priority and action restrictions where recorded.
4. Validate opportunity findings against synchronized POV footage, including cases where the support skill was used and failed to prevent a down.
