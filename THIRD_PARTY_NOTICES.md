# Third-Party Notices

Entropy is a custom frontend for viewing Guild Wars 2 World-vs-World combat
reports. It reads a `report.json` data format that is defined and produced by
**AxiBridge**, an open-source project by darkharasho.

## AxiBridge

- Project: https://github.com/darkharasho/axibridge
- Copyright (C) 2026 harasho
- License: GNU General Public License v3.0 (GPL-3.0-only)

AxiBridge's `@axiapps/bridge-metrics` package, and the surrounding aggregation
code in its `src/renderer/stats` and `src/shared` directories, define the
schema and computation logic (player aggregation, role classification, MVP
scoring, leaderboards, boon/condition tracking, fight breakdowns, etc.) that
`report.json` conforms to. Entropy's TypeScript types in `src/types/report.ts`
are written to match that upstream schema so that reports generated by
AxiBridge can be rendered by Entropy's UI.

**As of the raw-log combine feature, Entropy vendors real AxiBridge source
code.** The full contents of AxiBridge's `packages/bridge-metrics/src`
(published as `@axiapps/bridge-metrics`) are copied verbatim into
[`src/lib/bridge-metrics/`](./src/lib/bridge-metrics/), and
`src/renderer/stats/classifyPlayerRoles.ts` is copied (with import paths
adjusted for Entropy's layout, otherwise unmodified) into
[`src/lib/bridge-metrics/classifyPlayerRoles.ts`](./src/lib/bridge-metrics/classifyPlayerRoles.ts).
This code powers `src/lib/buildReportFromFights.ts`, which turns raw
per-fight Elite Insights logs (fetched via dps.report) into a combined
`report.json`-shaped object entirely client-side, in the browser — no
AxiBridge desktop app or server involved. `buildReportFromFights.ts` itself
is original Entropy code that reimplements AxiBridge's report-assembly logic
(leaderboards, MVP scoring, squad/enemy class breakdowns, attendance) by
reading the same source; it is not a copy, but it is a derivative work of a
GPL-3.0 program and should be treated as such.

Combined reports built this way currently omit several sections that only
exist in AxiBridge's non-portable, Electron-app-coupled aggregation code

generation tables/leaderboards, map/timeline data, and combat replay data.
Porting those is tracked as future work; the affected views show empty state
for reports built from raw logs today.

## GW2_EI_log_combiner

- Author: Drevarr
- License: GPL-3.0

Used in the local data pipeline (`axibridge_pipeline.py`) to merge parsed
Elite Insights logs into a single combined report before AxiBridge's
aggregation engine processes them. Not currently vendored into this
repository.

## Elite Insights Parser

- Project: https://github.com/baaron4/GW2-Elite-Insights-Parser
- License: MIT

Used as an external CLI tool to parse raw `.zevtc`/`.evtc` combat logs into
JSON. Not vendored into this repository; invoked as an external process.
